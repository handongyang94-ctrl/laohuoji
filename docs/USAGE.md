# 使用说明

## 一句话版

把源视频、脚本、截图、B-roll、音乐放到一个项目文件夹里，然后让 Codex 使用 `koubo-video-editor`。

## 典型任务

### 只剪口播

```text
用 koubo-video-editor 做 stage 1 口播粗剪。源素材在 xxx，脚本在 xxx。重点处理重复拍摄、气口、废话、停顿和逻辑顺序。
```

交付标准：

- 没有重复 take。
- 没有明显 raw 拍摄气口。
- 没有剪掉关键意义。
- 不把粗剪冒充成片。

### 做完整成片

```text
用 koubo-video-editor 完整做成片。源视频在 xxx，脚本在 xxx。要 B-roll、音乐、字幕、知识卡片、最终检查。
```

交付标准：

- 有 B-roll 扫描。
- 有音乐或明确的静音理由。
- 字幕和卡片不越界、不遮挡重点。
- 已抽帧检查。

### 做透明动效层

```text
用 koubo-video-editor 做透明动效层。视频已经粗剪完，不用处理气口。我要 1920x1080、60fps、带 alpha，可以直接放进剪映叠加。
```

交付标准：

- 透明通道存在。
- 不含原视频画面。
- 所有卡片在安全区。
- 检查最密集的一帧没有重叠。

### 做封面

```text
用 koubo-video-editor 给这条视频做 3:4 竖屏封面。必须用视频里的真人，不要生成假脸。
```

交付标准：

- 1080x1440。
- 人来自真实视频帧。
- 文案和视频内容一致。
- 风格和视频包装一致。

### 做技术拉片

```text
用 koubo-video-editor 给这条参考视频做技术拉片。重点拆剪辑手法，不要写影评。最后输出拉片报告和复现 SOP，尤其检查报告页和字幕不要互相遮挡。
```

交付标准：

- 先定拆解维度。
- 判断视频类型。
- 有粗抽帧；关键变化区间要细抽帧。
- 同时拆内容线和技术线，但重点放在技术线。
- 有按时间排列的拉片表。
- 有一句话结论、可复刻度评分、关键发现。
- 有工具链推断，并标明哪些是推断。
- 有可执行的 Jianying/CapCut 或 Remotion 复现 SOP。
- 有素材准备清单和复刻成本估算。
- 报告页、总结页、SOP 页不被字幕遮挡。

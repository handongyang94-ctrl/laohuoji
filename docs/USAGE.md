# 使用说明

## 先说边界

这个 Skill 有自动剪辑能力，但推荐的工作方式不是“全自动替你剪完”。

更稳的方式是：

```text
人负责剪映/CapCut/剪辑软件里的实际时间线。
AI 负责剪辑判断、问题发现、动效生成、拉片复盘和检查清单。
```

尤其是气口、句子头尾、表情状态、切点舒服不舒服，最好还是你自己在剪辑软件里看着时间线处理。AI 可以帮你指出哪里有问题，但不要把自动静音切割直接当最终剪辑。

## 推荐工作流

### 1. 先自己剪一版口播粗剪

在剪映、CapCut、Premiere 或你熟悉的剪辑软件里先做：

- 删除明显 NG
- 删除重复 take
- 收掉长停顿
- 保留自然判断停顿
- 确认句子头尾没有剪断

然后导出一个低清检查版，交给 Codex 用这个 Skill 检查。

推荐说法：

```text
用 koubo-video-editor 检查这个口播粗剪。源视频在 xxx，脚本在 xxx。气口我会自己在剪映里修，你帮我找重复表达、剪断句子、意义缺失、节奏拖沓和字幕遮挡风险。
```

交付应该包括：

- 问题清单
- 对应时间段
- 为什么是问题
- 建议回到时间线怎么修
- 哪些地方不要过度剪

### 2. 再做成片规划

粗剪没问题后，再让 Skill 做成片规划。

推荐说法：

```text
用 koubo-video-editor 给这条口播做成片规划。先拆意义单元，再规划每一段用真人、B-roll、截图、知识卡片还是不切画面。音乐要不要加也给判断。
```

交付应该包括：

- 意义单元表
- 每段视觉任务
- B-roll 使用理由
- 音乐或静音判断
- 字幕/卡片安全区提醒
- 最终抽帧检查点

### 3. 做透明动效层

这是重点功能。

适合在口播已经剪干净后使用。

推荐说法：

```text
用 koubo-video-editor 给这个已剪好的口播做透明动效层。不要合成底片，只输出能叠进剪映的 alpha 视频。重点做关键词、知识卡片、进度条和证据卡，注意不要挡脸和字幕。
```

交付应该包括：

- 透明动效视频路径
- 分辨率和帧率
- alpha 通道确认
- 最密集画面检查
- 字幕/脸/证据区域遮挡检查

注意：

- 动效层不是越多越好。
- 一张卡片只讲一个结论。
- 卡片要服务口播，不要抢口播。
- 如果字幕在底部，进度条和卡片不要挤到底部。

### 4. 做技术拉片

这是重点功能。

推荐说法：

```text
用 koubo-video-editor 拉这条参考视频。重点拆剪辑技术，不写影评。先粗抽帧，再对关键变化区间细抽帧。最后输出时间轴拉片表、技术动作表、工具链推断和复现 SOP。
```

交付应该包括：

- 视频类型判断
- 一句话结论
- 可复刻度评分
- 时间轴拉片表
- 内容线拆解
- 技术线拆解
- 字幕/字体/动效/镜头/节奏分析
- 工具链推断
- 复现 SOP
- 素材准备清单
- 哪些地方不能机械照抄

硬标准：

- 没有时间轴表，不算拉片。
- 没有复现 SOP，不算完成。
- 工具链只能推断，不能没有证据就说死。
- 如果输出报告页，要检查字幕不能挡住报告正文。

### 5. 封面

封面只是附带能力，不是这个 Skill 的重点。

如果要做，可以这样说：

```text
用 koubo-video-editor 给这条视频做 3:4 竖屏封面。必须用视频里的真人帧，不要生成假脸。
```

交付标准：

- 真人来自原视频
- 标题和视频内容一致
- 缩小到手机预览仍然能看清

## 常见错误

- 把自动剪出来的粗剪当最终成片。
- 气口没有人工复看。
- 字幕挡住嘴、产品、截图证据或 CTA。
- 透明动效层把底片视频也合进去了。
- 技术拉片写成观后感，没有时间轴。
- 复现 SOP 写成抽象建议，没有具体动作。
- B-roll 只是“相关”，但没有证明、解释或换气作用。

## 最推荐的用法

```text
自己先剪一版。
让 Skill 帮你检查。
你回到剪辑软件修。
再让 Skill 做动效、拉片、复盘和最终检查。
```

这就是人机结合。
